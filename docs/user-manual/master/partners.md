## Partners

A **partner** is a museum, an institution or another organisation that provides content. The sites print a partner on the item sheets of the items it holds, and in their partner lists.

The same museum can appear more than once in the **Partners** list, once per legacy project that recorded it: the *Museum für Islamische Kunst* exists for Discover Islamic Art, for the galleries and for other projects. Check the **Project** before you edit, and edit the record of the project whose site you maintain.

### The partner's fields

![A partner's Core Information]({{ '/user-manual/images/partner-view.png' | relative_url }})

| Field | What it does |
|---|---|
| **Type** | Museum, institution, individual… |
| **Country**, **Project** | |
| **Monument item** | For a partner that is a monument: the monument item. |
| **Category** | Legacy's partner category, used by Sharing History. |
| **Featured** | The Portal's own selection: the partner is shown in the featured strip of Explore and the galleries. |
| **City** | The city as Sharing History's partner list prints it, for every language. |
| **Latitude**, **Longitude**, **Map zoom** | The partner's position on the maps. |

### The partner's tabs

| Tab | What it holds |
|---|---|
| **Owned items** | The items the partner holds. |
| **Translations** | The partner's texts per language and context: **name**, **Also known as** (another name, as written), **City (display)**, **description**, the address and contact lines. |
| **Collection participations** | The collections the partner takes part in, with its level and visibility. |
| **Images** | Pictures of the partner's building or collection ([chapter 3]({{ '/user-manual/master/images' | relative_url }})). |
| **Logos** | The partner's logos ([chapter 3]({{ '/user-manual/master/images' | relative_url }}#partner-logos)). |
| **Links** | The partner's website, shop, virtual visit… |
| **Visit information** | How to visit the partner (below). |
| **Contacts** | The partner's contact persons. |

### Participations: whether a site lists the partner

A partner appears in a site's partner list through its **participation** in the site's collection or project.

![The collection participations of a partner]({{ '/user-manual/images/partner-participations.png' | relative_url }})

| Field | What it does |
|---|---|
| **Level** | *Partner* (provides content directly), *Associated Partner* (supports the collection), *Minor Contributor*. The project sites list only partners with a level. |
| **Visible** | Off: the partner is left out of the list. Its items still show. |
| **Parent partner** | Optional: another partner of the same collection that this partner takes part through (an associated museum under its main partner). Only the collection's own partners are offered. |

**Attach** adds a participation, **Edit** changes its level, visibility or parent partner, **Detach** removes it. You can do the same from the collection's **Partners** tab.

### Contacts

The **Contacts** tab holds the partner's contact persons: name, title, e-mail, phone, fax, in legacy's order (contact person 1, 2…). Some sites print the first two. These are personal data: change them only at the partner's request, and never copy them anywhere else.

## Visit information

**Visit information** tells a visitor how to reach a place and when it is open. The same model serves three kinds of record:

- **monuments** (an item's **Visit** tab);
- **locations** of Explore and Travels (a collection's **Visit information** tab);
- **partners** (a partner's **Visit information** tab).

![The Visit tab of a monument]({{ '/user-manual/images/visit-information.png' | relative_url }})

Each row is for one language and one context. **New visit information** adds a row; **Edit** changes one. The fields:

| Section | Field | What it holds |
|---|---|---|
| **Getting there** | **How to reach** | Directions. |
| | **Address** | |
| | **Opening hours** | |
| | **Practical information** | Anything else a visitor needs. |
| **Contact** | **Institution** | The institution responsible for the place. |
| | **Contact**, **Phone**, **Fax**, **E-mail**, **Website** | The place's contact lines. |

Every text is kept as written. As for the item translations, edit the row in the context of the site you maintain.
